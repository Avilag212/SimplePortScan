# SimplePortScan
This is a script in Python that simply check if a TCP port is open sending one SYN flag and detect if was received a flag RST or SYN-ACK. The pourpose of that is has a quickly way to just check if an TCP port is open.

How to use it: python3 sfc <port_number> <IP_or_hostname_target>
 
# PT-BR
Esse é um script Python que simplesmente checa se uma porta TCP está aberta enviando uma flag TCP SYN e verificando se foi recebida uma flag RST ou SYN-ACK. O propósito desse script é ter uma maneira rápida de simplesmente checar se uma porta TCP está aberta.

Modo de uso: python3 sfc <numero_da_porta> <IP_ou_hostname_do_alvo>
